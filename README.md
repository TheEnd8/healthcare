# Healthcare Info Hub — 投資情報工作台

## 主要頁面
- `index.html`：全球生技醫療情報總覽。
- `investment.html`：投資研究工作台，合併公司事件、監管事件與產業趨勢，支援全文搜尋、類型篩選、更新鮮度提示與規則式研究排序。
- `admin.html`：標的清單管理。

## 資料品質與測試
- `scripts/validate.mjs`：AI 事件的日期、必填欄位、來源 URL 與報導期間驗證。
- `tests/validate.test.mjs`：日期、URL、未來日期與事件欄位測試。
- GitHub Actions 在 PR 與 main push 時執行 `node --test tests/*.test.mjs`。

## 安全提醒
管理頁面的 Fine-grained token 僅在當次頁面記憶體中使用，不應儲存於 localStorage。請只授予單一 repo 的 Contents 讀寫權限，完成操作後清空 Token 欄位；若曾將 Token 存於共用或不可信裝置，請撤銷並重新建立。

## 限制
- 投資研究排序是可解釋的關鍵詞規則，不是模型評級或投資建議。
- URL 驗證只能確認 URL 格式與 HTTP(S) 協定，不能保證來源頁面仍存在、內容支持摘要或新聞已被獨立查證。
- 股價可能延遲或缺漏；重大事件應回到公司公告與官方監管來源核對。

### 未來催化劑追蹤
- 情報更新流程會另行搜尋未來臨床讀出、試驗里程碑、PDUFA/監管決策、CHMP 意見、上市申請、財報指引與商業里程碑，寫入 `data/report.json` 的 `cat` 陣列。
- 每筆催化劑包含公司、產品/試驗、類型、日期、日期狀態、摘要、來源名稱、來源網址與影響觀察；前端可獨立篩選並匯出 CSV。
- 未來日期不套用新聞事件的「僅限已發生事件日期」規則；催化劑只接受今日至未來三年的日期，且須具備 HTTP(S) 來源。這只能驗證格式與欄位完整度，不能保證日期或來源內容正確，重要日期仍應核對公司公告及官方監管機關。

### 催化劑狀態與日期異動
- 催化劑資料會保留最近 400 天內已發生或已到期的里程碑，以便追蹤已公布結果、延期、取消及逾期未確認事件。
- 狀態包括「即將到期」「今日到期」「日期已過・待確認」「日期曾變更」「結果已公布」「已延期」「已取消」。只有來源明確支持時，研究流程才應將事件標為結果已公布、延期或取消。
- 同一公司、產品/試驗、事件類型與標題的預定日期若改變，會保留舊日期、記錄日期與新日期，並在研究工作台顯示變更紀錄次數。
- 逾期不等於結果已公布；逾期但沒有可靠結果來源時，維持「日期已過・待確認」。

### 催化劑研究優先分數
- 工作台以 0–100 分提供規則式研究優先排序，拆成事件重要性（45%）、時間敏感度（30%）及來源品質（25%）。
- 卡片同時顯示三項子分數，方便研究者理解排序由來；來源品質依網址網域分類，只是啟發式提示，不能取代對原文內容與證據等級的審閱。
- 分數不是成功機率、股價預測或投資建議；事件類型、公司規模、現金跑道、競爭格局與商業價值仍需個別分析。

### 催化劑結果追蹤
- 催化劑紀錄可保存結果狀態、實際公告日期、結果摘要與後續影響，並顯示於投資工作台、納入 CSV 匯出。
- 結果狀態包括優於預期、符合預期、低於預期、結果不明、已延期、已取消及尚未公布；結果判斷必須有來源支持。
- 預定日期已過不代表事件已發生。只有找到可追溯公告時，才記錄實際日期與結果；無法核實時保留待確認，不推測結果。
